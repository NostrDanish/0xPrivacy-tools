Metadata Cleaner

Strip EXIF / location / camera metadata from images. The file is redrawn on a canvas in your browser — GPS, timestamps and device info cannot survive. Nothing is uploaded.

Method: decode → draw to <canvas> → re-encode. This reliably removes EXIF. PDF / Office metadata stripping is planned (needs a WASM lib) — track it on the repo.
