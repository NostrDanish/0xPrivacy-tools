# Security Audit — NostrDanish/0xPrivacy-tools — 2026-10-20

## Summary
Medium pass. Fully static, client-side-only PWA toolkit (password generator, hash calculator, converters, QR, metadata cleaner, ZK tools) — no backend, no accounts, no tracking by design. No package.json (plain HTML/JS with vendored libraries). No secrets of any kind found. Findings: 0 Critical / 0 High / 0 Medium / 3 Low.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| TLS-L1 | LOW | assets/js/lib/noble/* | Vendored @noble/hashes modules with no version manifest or update process — stale vendored crypto is a classic silent-risk. | Record upstream versions/hashes; add an update checklist or SRI. |
| TLS-L2 | LOW | sw.js | Service worker is cache-first (`hit || net`) and updates the cache in the background — users can run stale JS until cache version bump. Acceptable for offline-first, but pair every deploy with a CACHE version bump. | Bump `0xp-v1` on each release. |
| TLS-L3 | LOW | repo | No SECURITY.md. | Add a short security policy. |
